# Photo PowerPoint Slideshow Maker

A website for turning photos into a downloadable PowerPoint slideshow.

## What It Does

- Add photos by choosing files or dragging them into the app.
- Create one PowerPoint slide for each photo.
- Add as many photos as your browser and computer memory can comfortably handle.
- Reorder slides with the move buttons.
- Edit each slide's photo fit, background color, rotation, title, and speaker note.
- Download the slideshow as a `.pptx` PowerPoint file.
- Keep photos editable inside PowerPoint after export.

## Website

Photo PowerPoint Slideshow Maker is designed to run as a website. Visitors open the site in their browser, add photos, edit their slideshow, and download the finished PowerPoint file.

No account is required, and photos are handled in the browser while the slideshow is being created.

## How To Use It

1. Visit the website.
2. Click **Choose Photos** or drag photos into the upload area.
3. Select a slide from the slide list.
4. Adjust the selected slide using the edit controls.
5. Click **Download PowerPoint**.
6. Open the downloaded `.pptx` file in PowerPoint.

## Notes

- Photo filenames are not added as slide titles.
- The app labels slides as `Slide 1`, `Slide 2`, and so on.
- Large batches of high-resolution photos may take longer to import and export.
- For very large decks, add photos in batches and wait for the ready message before downloading.
